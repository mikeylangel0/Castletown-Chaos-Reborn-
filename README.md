# Castletown-Chaos-Reborn-
A 100% Vanilla TF2 Inspired Capture the Flag Map

13 years ago my brother, Suduski, and I created a Bukkit capture the flag map: LINK﻿

After months of work, with assistance from my brothers, I've fully remastered the map, and made it 100% vanilla. This map features TF2 classes, that function how you would expect, and a capture the flag system with 12 self-resetting locations.

If for any reason you spawn in the void enter the command: /tag @a add Spawn

Once each player selects their class, and the game is started, the attacking Red team will have 15 minutes to locate, and retrieve, the intelligence. The intelligence can be hidden in one of 12 locations throughout the main castle, and the surrounding areas.

It is advised that before playing a round you explore the map, and locate each possible intelligence location. They are not (that) hidden, and are marked with Blue wool. If you are super lost there is a file in the download with all the intelligence location coordinates.
Features:
All nine Team Fortress 2 classes in 100% vanilla. Each class has been meticulously built to be as close to the real TF2 class as possible.
Custom built texture pack featuring weapons, health packs, and more. Each model was hand made by me in Blockbench.
Dynamic command blocks allow command blocks to spawn, and de-spawn, as needed. Reducing server lag.
Magazines.
Health packs.
Spy backstab, invisibility, and sappers.
Engineer buildings.
Self resetting map. Want another game? Just start it!
Many hidden passages, and map features.

The uber-talented Drash2005 graciously allowed us to base this on a modified version of his astonishing map: Castle Hohenfels. LINK
Please check his work out, it's all genuinely mind blowing.

This map is fully playable, but I may tweak the balance. I plan on using this class system to recreate my favorite TF2 maps so stay tuned!

To install, unzip Castletown_Chaos.zip and move it to your save file.

The resource pack, TF2 items, is not strictly needed, but it will enhance the experience. Simply unzip the resource pack and place it in your resourcepacks folder.
